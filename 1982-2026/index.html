Banco de Dados Eleitorais do Brasil — Período Democrático

Eleições federais e estaduais · a partir de 1982 · FGV

← Página inicial

Este banco reúne resultados das eleições federais e estaduais realizadas no Brasil a partir de 1982, organizados por estado e região, com base nos dados publicados pelo Tribunal Superior Eleitoral.

Os dados são apresentados em formato eletrônico interativo, com tabelas, gráficos e arquivos para download. As imprecisões e divergências identificadas nas fontes aparecem em notas.

Apesar do esforço de verificação, o banco pode conter erros. Pesquisadores que identificarem alguma inconsistência nos dados podem enviar uma mensagem para o organizador, Jairo Nicolau (jairo.nicolau@fgv.br), indicando o cargo, o ano, o estado e, se possível, a fonte. Comentários e sugestões também são bem-vindos.
